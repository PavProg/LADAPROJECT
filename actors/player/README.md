# САМ ИГРОК
tscn + gd. Желательно скрипты не слишком нагружать, просчет физики имено игрока (как сервера, если непонятно желательно обратиться к сетевику).
Содержит в себе основные функции игрока (ходить, прыгать, спринтовать).
ОЧЕНЬ ВАЖНО кор-механики игрока (хватать/бить/бросать и тп) засовывать в components. ГОРАЗДО упрощает просчет физики и рэйкастов, не ломает шину сигналов.
