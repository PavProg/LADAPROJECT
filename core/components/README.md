# КОМПОНЕНТЫ
Основная функция каждую кор механику (и врагов, и игрока), выделить как отдельную для упрощения дебага, контроля 
и облегчения скриптов игрока. На примере grab:
	Основная функция игрока взятия находится здесь, то есть инпут от клиента (намерение) передается на сервер, сервер расчитывает рэйкаст
	(какой предмет берем), а также yaw и питч предмета (поворот по горизонт./вертикали), реплицирует на клиентов.
Функция подсчета для предметов, соответсвенно лежит в items.gd
